# APEX Fitness - Premium Gym & Fitness Website

![APEX Fitness](https://images.unsplash.com/photo-1534438327276-14e5300c3a48?w=1200&q=80)

## 🏋️ Overview

A modern, premium, and high-performance gym & fitness website with a **dark, bold, and energetic theme**. Designed to look professional, motivational, and conversion-focused, suitable for a high-end gym or fitness studio.

## ✨ Features

### Design & UI
- ✅ Modern dark mode with black/charcoal base
- ✅ Neon green, red, and orange accent colors
- ✅ Smooth animations and micro-interactions
- ✅ Full-width hero section with imagery
- ✅ Clean typography with bold headings
- ✅ Fully responsive (mobile, tablet, desktop)

### Sections
1. **Hero Section** - Motivational headline with dual CTAs
2. **Stats Counter** - Animated statistics (15 years, 5000+ members, 50+ trainers)
3. **About** - Mission, vision, and company story
4. **Programs** - 6 fitness programs with icons
5. **Pricing** - 3 membership tiers with "Most Popular" highlight
6. **Trainers** - 4 expert trainer profiles
7. **Schedule** - Weekly class timetable
8. **Testimonials** - Member success stories with ratings
9. **Gallery** - Gym photos with lightbox
10. **Contact** - Form, map, and contact info
11. **Footer** - Quick links and social media

### Functionality
- ✅ Working contact & enquiry forms
- ✅ Join Now & Free Trial modals
- ✅ Smooth scrolling navigation
- ✅ Real-time form validation
- ✅ Gallery lightbox
- ✅ Mobile hamburger menu
- ✅ Scroll animations
- ✅ SEO-friendly structure

## 🚀 Quick Start

### Option 1: Direct Open
Simply open `index.html` in any modern web browser.

### Option 2: Local Server (Recommended)
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server

# Then visit: http://localhost:8000
```

## 📝 Customization Guide

### Changing Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --color-accent-primary: #00ff41;  /* Change primary accent */
    --color-accent-secondary: #ff0040; /* Change secondary accent */
}
```

### Updating Content
- **Text**: Edit directly in `index.html`
- **Images**: Replace Unsplash URLs with your own
- **Pricing**: Update in the pricing section
- **Schedule**: Modify the table in schedule section

### Adding Features
- **New Section**: Copy existing section structure
- **New Animation**: Use `.fade-in` class
- **New Modal**: Follow modal pattern in HTML/JS
